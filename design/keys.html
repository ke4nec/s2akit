设计说明 · 与 v0.2.x 实现对齐（KeysView.vue，与账号页同源 tables.css）

卡片头：Key 页只有正常 / 停用两个计数 + 右侧「刷新 Key 列表」按钮（无分组胶囊——Key 不按分组过滤，元信息行显示所属分组名）。未登录时与账号页同样替换为「前往设置」提示条。标题栏与账号页同款，登录状态与窗口控制之间含「界面主题」快捷按钮（下拉 亮色 / 暗色 / 跟随系统，点击即生效并跨窗口同步）。
表格：列宽 216/84/132/104/96/150/150；行首竖条仅启用绿 / 停用灰两态；状态徽标正常绿 / 其余灰（错误状态也是灰徽标，错误信息经测试与悬停提示呈现）；首 token 失败显示 close-circle 红色图标；测试中骨架 shimmer + 按钮禁用。
用量列：主行「今日 $费用」（14px 半粗、等宽数字）+ 副行「次数 · token 量」（K/M 紧凑格式），悬停显示明细（请求数、输入/输出/缓存、缓存率、均值与费用）；数据由后台静默填充（失败留空显示 —，不阻塞表格）；该列按费用排序，无数据排最后。
托盘用量统计源：右键行「查看该 Key 额度」把该 Key 设为托盘菜单顶部用量统计对象（再点恢复汇总全部），被选中的 Key 名称后跟 11px 蓝色折线小图标（如首行 sk-main-pool）。行右键菜单完整项：查看该 Key 额度 / 选择模型测试（级联子菜单）/ 禁用（启用）该 Key。
操作列与分页与账号页同款（测试 + file-tree 选择模型测试；每页默认 10，页数 >7 收敛省略号）。色板对应 apple.css :root，暗色版见 keys-dark.html。
